# IKUN Music Desktop v1.4.5

## 新增

- 完成 AurioClub 播客能力迁移，支持账户、设备关联、订阅分组、热门发现、资料库、同步、播放与下载流程。
- 接入本地播客转写，支持分段识别、逐字时间轴、说话人区分与状态恢复。
- 支持播客逐字稿和博客正文的独立长内容协议，并可被 BetterLyrics 消费。
- 长内容分享支持分页预览、范围导出、批量生成、失败重试和取消操作。
- 分享链接优先返回原始文章地址；没有文章地址时回退到音频地址。

## 优化

- 播客资料库改为渐进加载，改善长列表浏览体验。
- 补充封面降级、触屏命中区、键盘操作和减少动态效果适配。
- 完善 RSS 文章元数据、原始链接和同步契约处理。

## 修复

- 修复 SQLite v8 索引结构被误判损坏后数据库连接关闭的问题。
- 修复播客封面属性类型错误。
- 修复长文本分页、分享链接实体编码和转写后端标识问题。

## 验证

- Vitest、主进程与渲染进程 TypeScript 检查通过。
- 主进程、渲染进程生产构建通过。
- SQLite 数据库迁移、完整性检查及播客分组查询通过。
